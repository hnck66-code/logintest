## Deskripsi
Project ini dibuat sebagai bagian dari tugas mata kuliah *Testing dan Implementasi Sistem*.  
Tujuannya adalah untuk mengembangkan sistem informasi berbasis web yang berfokus pada pengujian (testing) dan implementasi agar dapat berjalan dengan baik di lingkungan pengembangan maupun produksi.

---

## Fitur Utama
- Login dan registrasi pengguna  
- Pengelolaan data berbasis database MySQL (db_login)  
- Struktur folder yang rapi dan mudah dipahami  
- File db.sql disertakan untuk mempermudah proses import database  

---

## Cara Menggunakan
1. Clone repository ini ke dalam folder htdocs di XAMPP.  
2. Buat database baru di *phpMyAdmin* dengan nama:db_login
3. Import file database/db_login.sql  
4. Sesuaikan konfigurasi database di config/database.php.  
5. Jalankan project melalui browser local server (XAMPP) dll.
